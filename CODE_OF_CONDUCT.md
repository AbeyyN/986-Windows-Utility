# Code of Conduct

986 Windows Utility welcomes technical discussion, testing, documentation and code contributions from people of different backgrounds and experience levels.

## Expected behaviour

- discuss code and evidence, not personal characteristics
- be specific, reproducible and constructive in reviews
- respect security disclosures and user privacy
- do not publish secrets, private logs or identifying information
- accept that unsafe or unverifiable tweaks may be rejected

## Unacceptable behaviour

Harassment, threats, discriminatory abuse, deliberate misinformation, spam, malicious code, credential theft, destructive payloads and attempts to bypass the project's security process are not accepted.

## Enforcement

Maintainers may edit, hide, lock or remove abusive content and may restrict participation when necessary to protect the project or community.

Technical disagreement is allowed. Personal attacks are not.
